# pokemon-game

Juego diario de Pokemon: imagen difuminada que se va revelando intento a intento, reconocimiento de voz para adivinar el nombre y quiz generado por IA sobre ese Pokemon.

## Estructura

- `apps/frontend/` — Angular 21 (standalone, signals, zoneless) + Tailwind 4 + DaisyUI 5.
- `apps/backend/` — Spring Boot 3.4 + Java 25 + Spring AI.
- `infra/docker-compose.yml` — Postgres 17 + Ollama.
- `docs/superpowers/specs/` — documentos de diseño.
